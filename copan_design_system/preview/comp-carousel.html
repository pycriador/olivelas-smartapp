Carousel

Versão 1.0.0

O Carrossel é um padrão usado para apresentar conteúdo na forma de lista horizontal. A navegação entre as páginas pode ser feita usando os botões de anterior/próximo ou pelo gesto de swipe.

Paginação
Opções
Margem entre itens

O espaçamento entre os itens do carrossel possui 4 opções de tamanho, e pode ser alterado para se ajustar melhor ao contexto de uma interface.

Número de itens por página

Os itens por página podem variar entre um e quatro.

Navegação

É possível suprimir os botões de navegação. Quando não há botões, a navegação só é possível com o gesto swipe, e só deve ser aplicada em dispositivos móveis.

Auto paginação

O número de páginas é calculado automaticamente com base no número de itens filhos e do número de itens exibidos página.
