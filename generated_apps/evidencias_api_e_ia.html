✨ 2. Prompt Real Enviado à IA & Resposta Gerada

PROMPT REAL DO COPILOT (AI Gateway / Gemini 3.0 Flash) 
[PAPEL / PERSONA]
Você é o AI Wiki Copilot da Engenharia da Olivelas.
O desenvolvedor está consultando o guia técnico oficial de "Engenharia de Prompts e Tipagem Estrita".

[DÚVIDA DO DESENVOLVEDOR]
Como estruturar um modelo Pydantic v2 para validação de saída de um LLM em FastAPI, garantindo que campos extras sejam rejeitados e tipos numéricos sejam estritos? Forneça um exemplo funcional em Python.
RESPOSTA REAL GERADA PELA IA COM CÓDIGO 
No Pydantic v2, utilize `ConfigDict(extra="forbid", strict=True)` para garantir contratos 100% determinísticos na saída do LLM:

```python
from pydantic import BaseModel, Field, ConfigDict

class CreditAnalysisOutput(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True)
    
    status: str = Field(..., description="APPROVED, REPROVED ou MANUAL_REVIEW")
    score: float = Field(..., ge=0.0, le=1000.0, description="Score preditivo de crédito")
    approved_limit: float = Field(default=0.0, ge=0.0)
    risk_factors: list[str] = Field(default_factory=list)
```

No seu endpoint FastAPI, passe o schema acima no `response_model` para validação automática da resposta do AI Gateway.
