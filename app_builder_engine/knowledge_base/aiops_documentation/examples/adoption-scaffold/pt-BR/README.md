# Scaffold de adoção (starter vazio)

> Language: pt-BR | [English (EN)](../en/README.md)
>
> **Não é um produto.** Árvore vazia para copiar em um repositório adotante no Dia 0.
>
> Status: ACCEPTED
>
> Documentation Standard v1.0

## Como usar

1. Copie `docs/` para o repositório do serviço.
2. Preencha [docs/project-overview.md](docs/project-overview.md).
3. Siga o [Caminho de adoção](../../../docs/pt-BR/adoption-path.md).
4. Opcionalmente ative o [adopter-ci-starter](../adopter-ci-starter/).

## Aviso

Este scaffold é **orientação opcional**. Não é obrigatório para usar o Padrão de Documentação de Engenharia. Escolhas de tecnologia pertencem ao seu projeto.
