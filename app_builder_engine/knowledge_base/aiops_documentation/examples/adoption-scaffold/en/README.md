## How to use

1. Copy `docs/` into your service repository (or merge folders).
2. Fill [docs/project-overview.md](docs/project-overview.md).
3. Follow [Adoption path](../../../docs/en/adoption-path.md).
4. Optionally enable [adopter-ci-starter](../adopter-ci-starter/).

This scaffold is **optional guidance**. It is not mandatory for using the Engineering Documentation Standard. Technology choices belong to your project.
