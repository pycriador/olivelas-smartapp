> Documentation Standard v1.0


Ten rules for how AI agents navigate this documentation set.

1. **Start at [ai-context.md](ai-context.md).** Do not begin with a random deep page.
2. **Identify scope** (system, service, environment, timeframe) before loading Level 2+.
3. **Follow progressive context** ([progressive-context.md](progressive-context.md)); expand depth only as needed.
4. **Prefer Authoritative/Verified sources** ([authority-levels.md](authority-levels.md), [source-of-truth.md](source-of-truth.md)).
5. **Use the documentation graph** — typed links, registries, and [manifest.yaml](manifest.yaml) — over keyword guessing alone.
6. **Load domain hubs** when relevant: architecture-model, contract-model, operations-model, security-model.
7. **Check lifecycle status** — ignore Deprecated/Archived as current SoT unless history is requested.
8. **Seek evidence** for non-trivial claims ([evidence-model.md](evidence-model.md)).
9. **Stop for safety** on secrets, credentials, and out-of-boundary tasks ([ai-context-safety.md](ai-context-safety.md), [ai-task-boundaries.md](ai-task-boundaries.md)).
10. **Record gaps and contradictions** instead of hopping indefinitely ([knowledge-gaps.md](knowledge-gaps.md), [contradiction-model.md](contradiction-model.md)).
