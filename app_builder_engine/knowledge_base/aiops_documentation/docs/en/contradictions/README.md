# Contradictions Registry

> Language: EN | [Português (pt-BR)](../../pt-BR/contradictions/README.md)
>
> Documentation Standard v1.0

Store contradiction records here. Use [../templates/contradiction.md](../templates/contradiction.md).

## Status Tokens

`OPEN` | `INVESTIGATING` | `RESOLVED` | `ACCEPTED`

`ACCEPTED` means the contradiction is acknowledged with an explicit resolution strategy (not that both statements are true).

## Automation

Objective conflicts (duplicate IDs, conflicting manifest entries, broken refs) are detected by the linter. Semantic contradictions remain human-reviewed ([../contradiction-model.md](../contradiction-model.md)).
