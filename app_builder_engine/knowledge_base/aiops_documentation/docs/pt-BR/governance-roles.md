# Papéis de Governança

> Language: pt-BR | [English (EN)](../en/governance-roles.md)
>
> Status: ACCEPTED
>
> Documentation Standard v1.0

Papéis mínimos de governança. Uma pessoa/time pode acumular vários.

| Papel | Foco |
| --- | --- |
| **Documentation Owner** | Precisão do conteúdo de domínio |
| **Arquitetura Owner** | SoT de arquitetura e ADRs relacionados |
| **Segurança Owner** | Docs de segurança, exceções, classificações |
| **Operações Owner** | Runbooks, SLOs, docs de incidente/recuperação |
| **Repository Maintainer** | Estrutura do padrão, config de validação, gates de CI |

## Autoridade

Owners propõem e mantêm. Approvers (quando usados) aceitam. Maintainers controlam regras de validação e a política de artefatos gerados.

Contribuidores de IA nunca são owners implícitos ([ai-task-boundaries.md](ai-task-boundaries.md)).
