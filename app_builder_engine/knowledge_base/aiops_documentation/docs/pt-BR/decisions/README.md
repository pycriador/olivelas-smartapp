Categoria para Arquitetura Decision Records (ADRs) em projetos em adoção.

## Objetivo

Registrar decisões arquiteturais e suas consequências — não apenas descrever a arquitetura.

## Orientação

- Crie um ADR quando uma escolha material for feita ou alterada.
- Mantenha o status atualizado (`Proposed`, `Accepted`, `Deprecated`, `Superseded`, etc., conforme o template de ADR).
- Linke ADRs relacionados de forma bidirecional quando decisões se substituírem.
- Docs de arquitetura descrevem o estado atual; ADRs explicam o porquê.

## Template

Use [../templates/adr.md](../templates/adr.md).

## Nomenclatura

```text
adr-XXX-short-title.md
```

Exemplo: `adr-001-prefer-async-boundary.md`
