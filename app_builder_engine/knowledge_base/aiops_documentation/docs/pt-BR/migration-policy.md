# Política de Migração do Padrão Documental

> Language: pt-BR | [English (EN)](../en/migration-policy.md)
>
> Status: ACCEPTED
>
> Documentation Standard v1.0

```text
New Standard → Compatibility Analysis → Migration Plan → Migration → Validation → Review
```

1. Compare versões em [versioning.md](versioning.md).
2. Liste mudanças breaking vs aditivas.
3. Atualize manifests, metadados e gates.
4. Execute `docs:validate`.
5. Resolva ERROR; acompanhe WARNING como dívida/exceções.
6. Revisão humana para docs Authoritative.
