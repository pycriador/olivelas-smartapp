# Score de Saúde da Documentação

> Language: pt-BR | [English (EN)](../en/health-score.md)
>
> Status: ACCEPTED
>
> Documentation Standard v1.0

A saúde é reportada como **indicadores**, não como uma nota única obrigatória.

| Indicador | Significado |
| --- | --- |
| Cobertura | Cobertura no escopo de manifest / checklist |
| Validity | Contagem de ERROR == 0 |
| Frescor | WARNINGs de obsolescência em docs Authoritative |
| Rastreabilidade | Presença estrutural de claim/evidence onde usados |
| Ownership | Owners Authoritative presentes |
| Consistência | IDs, links, manifest |
| Prontidão para IA | AI context + assets de navegação presentes |

Se um projeto adotante agregar um score numérico, documente a fórmula explicitamente. Este repositório **não** exige um número único.
