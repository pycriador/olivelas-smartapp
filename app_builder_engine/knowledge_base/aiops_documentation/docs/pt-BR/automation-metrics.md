>
> Status: ACCEPTED

> Documentation Standard v1.0

Métricas sugeridas (adote apenas se acionáveis):

| Métrica | Propósito |
| --- | --- |
| Validation runs | Garantir que gates executam |
| Validation failures | Detectar regressões de qualidade |
| Warnings | Acompanhar pressão de dívida |
| Open / expired exceptions | Higiene de governança |
| Stale documents | Pressão de freshness |
| Broken references | Navegabilidade |
| Missing ownership | Accountability |
| Missing evidence | Qualidade de claims |
| Documentation coverage | Honestidade de escopo |

Não crie métricas de vaidade.
