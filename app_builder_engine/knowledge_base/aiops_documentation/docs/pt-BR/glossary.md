# Glossário de documentação AI-Ready

> Language: pt-BR | [English](../en/glossary.md)
>
> Status: ACCEPTED
>
> Documentation Standard v1.0


Glossário dos **termos AI-ready deste Documentation Standard**. Glossários de domínio do projeto permanecem separados; siga o mesmo padrão (termos estáveis, tokens em inglês onde machine-readable).

| Term | Definition |
| --- | --- |
| **AI-ready documentation** | Docs estruturados com identity, metadata, evidence, relationships e constraints para que a IA os use com segurança — sem exigir produtos de RAG |
| **Authority level** | Peso de uma fonte: Authoritative, Verified, Informational, Reference, Historical, Draft, Unknown |
| **Claim** | Afirmação assertiva atômica que pode ser classificada e evidenciada |
| **Classification** | Relação de evidência de uma claim: Confirmed, Inferred, Proposed, Unknown, Deprecated |
| **Confidence** | Confiança em uma claim/resposta: High, Medium, Low, Unknown — não é status de ciclo de vida |
| **Component** | Unidade arquitetural de responsabilidade |
| **Context pack** | Conjunto mínimo de docs/excerpts montado para uma tarefa |
| **Documentation drift** | Docs ≠ realidade autoritativa |
| **Documentation graph** | Nós (docs) + arestas de relacionamento tipadas |
| **Evidence** | Artefato que sustenta ou refuta uma claim |
| **Frescor** | Quão atual um doc está em relação à realidade e à política de revisão |
| **Knowledge gap** | Item Known / Unknown / Assumed / Needs Verification |
| **Manifest** | Inventário machine-oriented de documentos |
| **Progressive context** | Profundidade expansiva da pergunta à resposta por níveis |
| **Service** | Unidade operável/executável; não é idêntica a component |
| **Source of truth (SoT)** | Artefato autoritativo para uma classe de informação |
| **Deprecated (claim)** | Claim retirada/supersedida; não é SoT atual |
