# Ciclo de Revisão de Governança

> Language: pt-BR | [English (EN)](../en/governance-review.md)
>
> Status: ACCEPTED
>
> Documentation Standard v1.0

O padrão e seus gates devem ser revisados periodicamente (preferencialmente orientado a eventos).

Avalie:

- regras inúteis ou excessivas;
- falsos positivos;
- docs redundantes;
- automações quebradas;
- lacunas e novas necessidades.

Resultados: manter, ajustar severidade, desabilitar com exceção ou substituir a regra.
