# ADR-0002: Arquitetura Geral

**Status:** Aceito  
**Data:** Setembro de 2026  
**Parent Standard:** ADR-0001 — Filosofia da Plataforma  

---

## Contexto

A plataforma necessita processar especificações complexas, gerenciar múltiplos catálogos (componentes, regras, templates, arquiteturas) e atender a requisições síncronas e assíncronas de agentes de IA de maneira performática e escalável.

---

## Decisão

Adotou-se uma arquitetura em camadas limpas (Clean Layered Architecture) com suporte assíncrono nativo em **Python 3.13+** e **FastAPI**, em conformidade com o *Loft Backend Foundation*.

### Diagrama de Arquitetura

```text
                           +------------------------+
                           |      AI Assistant      |
                           | Cursor • Claude • AGY  |
                           +-----------+------------+
                                       |
                                   HTTP / API
                                       |
                                       ▼
                     +-----------------------------------+
                     |        App Builder Engine         |
                     +-----------------------------------+
                     |                                   |
                     |  [API Layer]                      |
                     |  FastAPI Routers (REST / OpenAPI) |
                     |                                   |
                     |  [Application Services]           |
                     |  Builder • Knowledge • Catalog    |
                     |  Rules • Architecture • Template  |
                     |                                   |
                     |  [Domain Layer]                   |
                     |  Entities • Value Objects         |
                     |                                   |
                     |  [AI Gateway Layer (AI-BAS)]      |
                     |  LLMGateway • Providers • Prompts |
                     |                                   |
                     |  [Storage / Ingestion Layer]      |
                     |  SDD Loader • Canonical Seed Data |
                     |                                   |
                     +-----------------------------------+
```

### Camadas da Aplicação

1. **API Layer (`app/api/v1/`)**: Exposição dos contratos HTTP REST, serialização e validação estrita via Pydantic v2.
2. **Services Layer (`app/services/`)**: Orquestração dos use cases e da inteligência do Project Builder.
3. **Domain Layer (`app/domain/`)**: Entidades e regras de domínio puras, desacopladas de frameworks.
4. **AI Layer (`app/ai/`)**: Gateway agnóstico para provedores de IA, aderente ao padrão **AI-BAS**.
5. **Storage & Ingestion Layer (`app/storage/`)**: Parser e indexador de documentos SDD e sementes canônicas.

---

## Consequências

- **Alta Testabilidade:** Cada serviço e parser pode ser testado isoladamente sem necessidade de infraestrutura pesada.
- **Desacoplamento:** A API REST expõe apenas contratos tipados; nenhuma camada vaza detalhes internos de persistência.
