# ADR-0005: Knowledge Engine & SDD Loader

**Status:** Aceito  
**Data:** Setembro de 2026  
**Parent Standard:** ADR-0001 — Single Source of Truth  

---

## Contexto

O ecossistema Olivelas possui uma base documental rica (SDDs de Frontend Volumes I-IV, SDDs de Backend Volumes I-VI, Design System Copan e CLAUDE.md). Essa documentação precisa ser acessível dinamicamente via busca textual semântica e por volume para fornecer contexto aos agentes.

---

## Decisão

Implementar o módulo `SDDLoader` e `KnowledgeService`:
1. **Varredura Automática:** Na inicialização, a engine varre os diretórios `sdd-frontend/`, `sdd-backend/`, `copan_design_system/` e o arquivo `CLAUDE.md`.
2. **Indexação:** Os documentos são classificados por categoria (`frontend_spec`, `backend_spec`, `design_system`, `master_guide`), volume, tags e pontos-chave.
3. **Mecanismo de Busca:** Permite consultas textuais com ranqueamento de relevância e extração de snippets (`/api/v1/knowledge/search`).

---

## Consequências

- Atualizações na documentação markdown são imediatamente refletidas na API sem necessidade de rebuild de banco de dados.
- Agentes de IA podem consultar seções específicas de um SDD em tempo de execução via API.
