# ADR-0004: Padrão API First

**Status:** Aceito  
**Data:** Setembro de 2026  
**Parent Standard:** Loft Backend API Specification (BAS)  

---

## Contexto

Agentes de IA e ferramentas de automação necessitam de interfaces de comunicação com contratos estritos, previsíveis e fortemente tipados para evitar erros de interpretação e garantir interoperabilidade.

---

## Decisão

1. **Versionamento de URL:** Todos os endpoints são prefixados com `/api/v1/`.
2. **OpenAPI / JSON Schema:** Toda rota possui especificação OpenAPI completa gerada automaticamente pelo FastAPI + Pydantic v2.
3. **Padrão de Resposta para Coleções (Envelope):**
   ```json
   {
     "data": [ ... ],
     "meta": {
       "page": 1,
       "page_size": 20,
       "total_items": 100,
       "total_pages": 5
     }
   }
   ```
4. **Padrão Uniforme de Erros:**
   ```json
   {
     "error": {
       "code": "RESOURCE_NOT_FOUND",
       "message": "Component with ID 'fe-invalid' not found.",
       "details": {},
       "request_id": "req_123456789abc"
     }
   }
   ```
5. **Rastreabilidade:** Todo request HTTP recebe e propaga um `X-Request-ID` e `X-Process-Time-Ms`.

---

## Consequências

- Qualquer agente ou sistema pode consumir o App Builder Engine de forma padronizada.
- A validação de payloads é determinística e automática antes de atingir os serviços de aplicação.
